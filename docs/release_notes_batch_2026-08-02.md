# 버그/성능 수정 배치 보고 (2026-08-02)

## 이번에 고친 것 (fix/ui-perf-batch-1)

1. **안드로이드 통합검색 복구** — v1.1.5 상단바 개편 때 모바일 화면에서 통합검색 진입점이 사라졌던 회귀. 모바일 상단 AppBar에 검색 버튼을 복구.
2. **유선회원 문자/카카오 버튼** — 고객DB와 동일한 카카오 로고(노란 배경)/문자 아이콘 버튼으로 통일 (PC·모바일 툴바 모두).
3. **승인현황 뒤로가기 프리징** — 근본 원인은 화면 복귀 시 앱이 13개 페이지 전부를 다시 만들던 구조. 페이지 인스턴스를 캐시해서 해결 — 모든 화면 전환이 함께 빨라짐. 승인현황 화면 자체도 모바일 레이아웃 추가 + 통계 계산 최적화.
4. **감사로그 버벅임** — 전체 무제한 조회 → 최근 500건, 화면에 안 보이는 행까지 전부 그리던 것 → 보이는 부분만 렌더링, 검색 입력마다 전체 재계산 → 300ms 디바운스 + 사전 계산.
5. **모델명 관리** — 직원관리 헤더의 버튼 잘림(고정폭 900px 문제) 수정, 매핑 페이지 검색 프리징(키 입력마다 전체 재조인) 수정.
6. **엑셀 내보내기 고객 누락 (민병우 건)** — 원인 2중:
   - (잠재) 서버가 1000행 넘으면 조용히 잘라 보내는데 대비가 없었음 → 전량 로드 루프 적용 (고객DB/가망고객/유선회원/고객정리 전부).
   - (실제 원인) **민병우 고객의 매장이 비어 있음(NULL)** → 매장 필터(이대점 등)를 걸면 어느 매장에도 안 잡혀 화면·엑셀 모두에서 누락. 휴지통과 무관. ⚠️ 데이터 수정 필요 — 아래 "조치 필요" 참고.
7. **모바일 로그인 유지** — 종료 버튼이 모바일에서도 로그아웃까지 시키던 것 수정(앱만 닫힘, 세션 유지). 일시적 네트워크 끊김에도 강제 로그아웃하던 정책 체크를 "명시적 거부일 때만 로그아웃"으로 수정. 사원 IP 차단 정책은 그대로 동작.
8. **안드로이드 업데이트 후 구버전 잔존** — 업데이트 다운로드를 연 뒤 이전 버전 프로세스를 자동 종료하도록 수정. 중복 태스크를 유발할 수 있던 매니페스트 설정(taskAffinity) 제거.
9. **문자/카톡 매장명 하드코딩 제거** — 모든 발송 문구가 '이대역점' 고정이던 것을 현재 로그인 매장명으로 치환. 매장 확장 대비.

## 매장 추가 점검 결과 (신규 매장 개설 절차)

1. **매장 생성**: 사이드바 → 매장 추가 (대표/개발자만).
2. **매장 네트워크 등록** (중요): 매장관리 화면에서 해당 매장의 공인 IP 등록. **그 매장의 와이파이에 연결된 기기에서** "현재 네트워크 등록"을 실행해야 함. 미등록 시 그 매장 사원은 전원 로그인 차단됨.
3. **직원 연결**: 직원관리에서 직원의 매장을 새 매장으로 지정.
4. 참고: 회원가입 시 매장명이 자유 입력이라 오타 시 유령 매장이 생김 → 다음 배치에서 드롭다운 전환 권장.
